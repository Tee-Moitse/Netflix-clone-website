# Netflix Clone Website🎬

A front-end recreation of the Netflix landing page, built with plain HTML, CSS and JavaScript.

This project isn't tied to a job application or a deadline, it's something I'm building for the fun of it. It's a reminder of why I wanted to get into tech in the first place, a project for me to just be creative and a space to keep sharpening my Frontend skills one section at a time.


## Features

- Full-screen hero section with background image overlay
- Email sign-up input with a "Get Started" CTA, matching Netflix's real layout
- A custom curved section divider between the hero and content sections
- Multiple feature sections ("Enjoy on your TV", "Download your shows", "Watch everywhere", "Create profiles for children") alternating image/text layout
- A section of with FAQs with regards to the website
- A footer section

## Built With

- **HTML5** — semantic page structure
- **CSS3** — layout (Flexbox), gradients, custom dividers, responsive media queries
- **Font Awesome** — icon library (via CDN)
- **JavaScript** - interactivity for the faq panels

## Project Structure

```

   ├── style.css           # Core styling
```

## Running Locally

No build tools or dependencies needed — it's plain HTML/CSS and JavaScript.

1. Clone the repo
   ```bash
   git clone https://github.com/Tee-Moitse/Netflix-clone-website
   ```
2. Open `index.html` in your browser

That's it.

## What I Learned / Practiced

- Building responsive layouts with Flexbox
- Styling custom shapes with `clip-path` and SVG paths
- Debugging horizontal scroll/overflow issues caused by `vw` units vs `%`
- Working with background images, overlays, and gradients
